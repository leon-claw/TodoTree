# 导航、详情布局与标签页整改计划

**目标：** 列表和图表空白处均可关闭详情；列表详情固定悬浮在右侧；图表、列表、设置按指定顺序作为主 Tab；标签管理移入带返回的子页面；详情与设置子页均有可直达 URL，主 Tab 切换不增加历史记录；完成按钮两种状态边框尺寸一致。

**实现选择：** 使用浏览器 History API 的路径路由，不引入路由依赖。主 Tab 通过 `replaceState` 更新 URL；打开待办详情或标签管理子页时用 `pushState` 入历史，详情中改选其它待办时替换当前详情 URL。返回或点击空白区域可回到父视图。
